BookToBox - Play Store Compliance and Data Handling

This page explains how BookToBox aligns with Google Play requirements for transparency and protection of user and device-related data.

1. App purpose

BookToBox is an Android app for local inventory management of physical books. It allows users to create boxes, assign books to them, generate one PDF list per box, and share that PDF through standard Android share actions.

2. Data processed

To provide its core features, the app may process the following data categories:

  • Book photos: front cover, back cover, and optional ISBN/barcode photo.
  • Book metadata: title, author, and ISBN when available.
  • Organization metadata: box name and optional box location.
  • Derived files: generated box inventory PDF documents.

3. Purposes of processing

  • Provide book inventory and box-based lookup features.
  • Prefill ISBN/title/author from photos when extraction is available.
  • Generate printable PDF lists to identify box contents.
  • Enable local PDF sharing only when explicitly requested by the user.

4. Android permissions used

  • CAMERA: capture book photos and scan ISBN barcodes.
  • INTERNET: technical support for some libraries; no cloud inventory upload in MVP scope.

5. Storage and sharing

BookToBox follows a local-first model: boxes, books, photos, and generated PDFs are stored locally on the device as part of normal app behavior.

In MVP scope, the app does not provide cloud sync or automatic publishing to marketplaces. Data sharing occurs only when the user explicitly triggers the "Share" action for a generated PDF.

6. User control and transparency

  • Users choose which books and data are added to the app.
  • Users can manually correct extracted metadata before saving.
  • Users can manage and remove stored boxes and books from within the app.

7. Google Play compliance statement

Play Store data safety disclosures should reflect this behavior: functional data handling limited to local inventory use, no sale of personal data, and no cloud inventory upload within the current MVP scope.
